Gatit · Code signing policy

Privacy policy

Effective 16 October 2026. This policy describes Gatit's public source and the Windows Store edition being prepared. Gatit is an open-source desktop application maintained by Yarin Barry. It does not operate a central service that receives your calls.

Recordings and local processing

When you start a recording, Gatit captures microphone and computer audio. On supported Macs it can also capture a call window as video. It stores recordings, transcripts, summaries, participant names, meeting titles, settings and a local search index in your user profile. Transcription runs locally with whisper.cpp. Recording and transcription do not upload audio to a speech service.

Local files are ordinary files protected by your operating system and account permissions; Gatit does not provide separate encryption for the meeting library. The Claude API key and Google Drive OAuth credentials are kept in the macOS Keychain or Windows Credential Manager.

Optional services you configure

  • Anthropic/Claude: If you provide an API key, summaries send transcript text, known participant names and meeting context to Anthropic. Audio/video is not sent to Anthropic by Gatit. Automatic summarization is enabled by default after a key is configured; turn it off in Settings or remove the key to stop automatic summaries. Manual summaries also send this text. Anthropic privacy policy.
  • Google Drive: If you connect your own OAuth client and Google account, automatic uploads are enabled by default. Gatit uploads existing and new meeting folders, including audio, available video, transcripts and summaries, and uploads changes later. Pause automatic uploads in Settings or disconnect Drive. Access uses the drive.file scope for files Gatit creates. Google privacy policy.

The configured providers receive the content above plus information needed to process network requests, including your IP address and account authentication. Their policies and your account settings govern their retention. Gatit does not control data after it is sent to those services.

Downloads, updates and this website

When a required model is missing, transcription or an explicit model-download request downloads it from Hugging Face. These downloads send ordinary connection information, not your recordings or transcripts. The direct-download edition checks GitHub for updates automatically and may download an update; macOS installs it in the background, while Windows waits for the restart/update action. The Store edition delegates updates to Microsoft Store. Windows uses Microsoft's WebView2 runtime; installation or opening its download page contacts Microsoft.

This website is hosted on GitHub Pages and requests public release metadata from GitHub. Hosting, downloads, update and runtime services can receive IP addresses and request metadata under their policies: Hugging Face, GitHub, and Microsoft. Gatit's application code does not include a separate analytics or advertising service.

Your controls and deletion

You choose when to record and can disable call prompts or video capture in Settings. The app's Open meetings folder command shows your local files. Deleting a meeting removes the local copy through the operating system's trash/recycle-bin mechanism. Deleting a meeting also requests that its linked Google Drive folder be moved to Drive trash. Check Drive separately if that request fails. Exports, backups and content already sent to Anthropic may remain; manage those through the relevant service. Uninstalling the app is not a promise to erase all local or cloud copies. Keep a backup before changing editions or removing data.

Contact and changes

For a privacy question, contact the maintainer through the maintainer profile or the issue tracker. Issues are public: do not post private recordings, transcripts, keys or personal information. Updates to this policy will be committed in the public repository.
